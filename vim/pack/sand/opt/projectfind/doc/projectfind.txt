*projectfind.txt*   :find shortcuts for directories you visit constantly

==============================================================================
USAGE                                                   *projectfind-usage*

Define the places you jump to over and over in your vimrc: >

    let g:projectfind_paths = {
      \ 'kb': ['**/libs/entities/basetypes/', 'Knapp basetypes'],
      \ 'kl': ['**/libs/entities/lookup/',    'Knapp lookups'],
      \ }
    packadd! projectfind
<
That generates |:find| mappings under |g:projectfind_prefix| (default
`<leader>`), so `<leader>kb` puts >
    :find **/libs/entities/basetypes/
<on the command line and leaves it there - 'wildmenu' completion takes over
from that point. The description is also handed to |keyclue| if loaded.

==============================================================================
COMMANDS                                             *projectfind-commands*

:ProjectFindList                                        *:ProjectFindList*
        Show every configured key, description and path.

:ProjectFind {key}                                          *:ProjectFind*
        Same as pressing the mapping for {key}. Completes on keys.

==============================================================================
CONFIGURATION                                          *projectfind-config*

                                                     *g:projectfind_paths*
Dictionary of `key : [path, description]`. A bare string instead of a list
also works when you do not want a description.

                                                    *g:projectfind_prefix*
Mapping prefix, default `<leader>`.

                                               *g:projectfind_no_mappings*
Set to 1 to get the commands but no mappings.
